# Meeting Assistant design system

Dark only. Black surfaces, the system font, one sky-blue accent, red reserved
for recording. While recording the screen holds a breathing blue-to-violet
aurora and one stop control, nothing else. Pill buttons and inputs, round
controls with a small label under them.

Brief and the reasoning behind every token: `../system-brief.md`. Decision:
`DECISIONS.md` D1 at the repo root.

- `tokens/` colours, type, spacing, motion as CSS custom properties
- `styles.css` the components, one class each
- `guidelines/` one small page per foundation and component, each marked with `@dsCard`
